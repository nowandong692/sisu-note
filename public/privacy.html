국궁록 개인정보처리방침

시행일: 2026년 11월 27일 (이전 방침: 2026년 11월 21일)

국궁록은 국궁 시수를 기록하는 웹앱입니다. 개인정보를 되도록 받지 않도록 만들었습니다. 이메일, 이름, 전화번호, 프로필 사진은 받지도 저장하지도 않습니다.

1. 기기 안에만 저장하는 것

순 기록, 장비, 메모, 날씨, 활터, 설정은 기본적으로 쓰는 사람의 휴대폰(브라우저) 안에만 저장됩니다. 랭킹에 참여하지 않으면 국궁록 서버로 아무것도 올라가지 않습니다.

2. 랭킹에 참여하면 서버에 저장하는 것

닉네임을 정하고 랭킹에 참여한 경우에만 아래 정보를 서버에 저장합니다.

항목쓰는 곳
닉네임, 소속 활터 이름, 단, 등급, 대표 칭호랭킹과 활쏜얘기 탭에 표시
순마다 날짜, 저장 시각, 다섯 시의 관중 여부랭킹 계산
순 기록 백업: 시마다 과녁에 찍은 위치, 태그, 메모(공개하지 않은 메모 포함), 날씨, 쓴 장비와 활터기기를 바꾸거나 저장소가 지워졌을 때 본인만 되살림
하루 메모 백업 (공개하지 않은 메모 포함)
장비·설정 백업: 장비 목록, 등록한 활터의 이름과 위치(위도·경도)·사대 방향, 소속, 단, 메모 태그, 화면 설정
공개로 고른 메모·태그, 댓글활쏜얘기 탭 (전체 또는 같은 활터 궁사에게 닉네임과 함께 보임)
궁사·메모·댓글 신고 (신고한 궁사, 대상, 사유)운영자가 살펴보고 처리
복구 코드의 해시본인 확인 (복구 코드 원문은 저장하지 않음)

서버를 빌려 주는 Supabase와 앱을 올린 GitHub Pages는 서비스를 운영하면서 접속 기록(IP 주소, 브라우저 정보, 접속 시각)을 남길 수 있습니다. 국궁록은 이 기록을 따로 모으거나 쓰지 않습니다.

3. 카카오·구글 로그인

로그인은 복구 코드를 잃었을 때 기록을 되찾기 위한 선택 기능입니다.

  • 카카오는 동의 항목 없이, 구글은 최소 범위(openid)로만 로그인합니다. 이메일·이름·프로필은 요청하지 않습니다.
  • 로그인 회사가 주는 계정 번호는 원문으로 저장하지 않고, 되돌릴 수 없는 해시 값만 저장합니다.
  • 복구 코드는 그 계정으로 다시 로그인해야만 열리도록 잠가서 보관합니다.
  • 로그인 과정에서 받은 토큰은 계정 번호를 확인하는 데만 쓰고 바로 버립니다.
  • 구글 자동 로그인: 기록이 없는 기기에서 앱을 열면, 버튼을 누르지 않아도 구글 로그인 스크립트(accounts.google.com)를 불러옵니다. 이 브라우저에 구글 계정이 로그인되어 있으면 구글이 작은 확인 창을 띄우거나, 예전에 국궁록에 연결한 계정이면 바로 계정 토큰을 넘겨줍니다. 이 과정에서 구글이 자기 쿠키를 읽을 수 있습니다. 연결한 적 없는 계정이면 아무것도 저장하지 않습니다.

4. 운영자가 볼 수 있는 것

부정한 기록과 신고를 처리하기 위해 운영자는 관리자 화면에서 다음을 할 수 있습니다.

  • 닉네임으로 궁사를 찾아 날짜별·순별 관중 기록 보기, 그 기록 지우기
  • 궁사를 랭킹에서 숨기기, 부적절한 닉네임 초기화
  • 신고된 메모·댓글과 신고 사유 보기, 지우기

관리자 화면에는 공개하지 않은 메모, 백업 내용, 복구 코드, 로그인 계정 번호가 나오지 않습니다.

5. 다른 서비스로 보내는 것

  • 위치: 날씨와 근처 활터를 찾을 때, 허락한 경우에만 기기의 위치(위도·경도)를 날씨·지도 서비스(Open-Meteo, MET Norway, wttr.in, OpenStreetMap)로 보냅니다. 기기의 현재 위치는 국궁록 서버에 저장하지 않습니다. 다만 직접 등록한 활터의 위치는 랭킹 참여 중이면 장비·설정 백업에 함께 저장됩니다(2항).
  • 활터 검색: 활터 이름을 찾을 때 검색어와 기준 위치를 카카오(카카오맵 장소 검색)로 보냅니다.
  • 로그인: 카카오·구글 로그인을 쓰면 카카오(kauth.kakao.com)와 구글(accounts.google.com)로 이동하거나 그 스크립트를 불러옵니다.
  • 대회 영상: 대회 탭에서 영상을 틀면 유튜브에서 영상을 불러옵니다. 지난 영상은 쿠키를 줄인 youtube-nocookie.com을 쓰지만, 생중계는 youtube.com에서 불러와 유튜브 쿠키가 쓰일 수 있습니다.
  • 글꼴: 화면 글꼴을 Google Fonts에서 불러옵니다.
  • 호스팅: 서버는 Supabase에, 앱은 GitHub Pages에 올라가 있습니다.

6. 국외 이전

랭킹에 참여하면 2항의 정보가 해외 회사의 서버에 저장되거나 그 회사를 거칩니다. 앱을 쓸 때마다 인터넷으로 보내지며, 랭킹 참여를 그만두면 지워집니다.

받는 곳나라보내는 것
Supabase Inc.호주 (시드니 데이터센터, 운영 회사는 미국)2항의 랭킹·백업·공개 메모 정보, 접속 기록
GitHub Inc.미국앱을 불러올 때의 접속 기록
Google LLC미국구글 로그인 토큰 확인, 글꼴·영상을 불러올 때의 접속 기록

국외 이전을 원하지 않으면 랭킹에 참여하지 않고 기기 안에서만 쓰면 됩니다.

7. 보관 기간과 지우기

서버에 있는 정보는 랭킹 참여를 그만둘 때까지 보관합니다. 랭킹 참여를 그만두면(겨루기 탭 → 프로필 → "랭킹 참여 그만두기") 서버에 있는 그 궁사의 기록, 백업, 공개 메모, 댓글, 신고, 로그인 연결이 모두 바로 지워지고 되살릴 수 없습니다. 로그인 연결만 끊으려면 설정 탭의 "로그인 연결"에서 "연결 끊기"를 누르면 됩니다. 기기 안의 기록은 설정 탭의 데이터 지우기로 지울 수 있습니다.

8. 이용자의 권리

  • 내 기록은 앱에서 언제든 보고(열람), CSV로 내보낼 수 있습니다.
  • 닉네임·소속·단은 설정 탭에서 고칠 수 있고, 순 기록과 메모는 지우거나 고치면 서버 백업에도 반영됩니다.
  • 랭킹 참여를 그만두면 서버의 정보 전체가 지워집니다(삭제·처리 정지).
  • 앱에서 하기 어려운 요청은 9항의 문의처로 알려 주시면 처리합니다.

9. 만 14세 미만

국궁록은 보호자 동의를 확인할 방법이 없어, 만 14세 미만은 랭킹에 참여하지 않도록 해 주세요. 기기 안에서만 쓰는 기능은 그대로 쓸 수 있습니다.

10. 안전하게 지키는 방법

  • 모든 통신은 HTTPS로 암호화합니다.
  • 서버 테이블은 바깥에서 바로 읽을 수 없게 막고, 정해진 기능으로만 본인 정보를 읽고 씁니다.
  • 복구 코드와 로그인 계정 번호는 해시로만 저장하고, 관리자 코드도 저장소에 넣지 않습니다.

11. 광고와 제3자 제공

지금은 광고가 없고, 저장한 정보를 다른 곳에 팔거나 넘기지 않습니다. 광고를 넣게 되면 이 방침을 먼저 고쳐 알리겠습니다.

12. 개인정보 보호책임자와 문의

  • 개인정보 보호책임자: 국궁록 운영자
  • 문의: GitHub 저장소의 Issues

개인정보 침해에 대한 상담은 아래 기관에도 할 수 있습니다.

  • 개인정보분쟁조정위원회 (1833-6972, www.kopico.go.kr)

13. 방침이 바뀔 때

이 방침을 바꾸면 시행일을 고치고, 이 페이지와 앱 설정 탭의 링크로 알립니다. 서버에 저장하는 정보가 늘어나는 변경은 앱 안에서도 미리 알립니다.
