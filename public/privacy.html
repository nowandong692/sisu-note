국궁록 개인정보처리방침

시행일: 2026년 11월 21일

국궁록은 국궁 시수를 기록하는 웹앱입니다. 개인정보를 되도록 받지 않도록 만들었습니다. 이메일, 이름, 전화번호, 프로필 사진은 받지도 저장하지도 않습니다.

1. 기기 안에만 저장하는 것

순 기록, 장비, 메모, 날씨, 설정은 기본적으로 쓰는 사람의 휴대폰(브라우저) 안에만 저장됩니다.

2. 랭킹에 참여하면 서버에 저장하는 것

항목쓰는 곳
닉네임, 소속 활터 이름, 단랭킹에 표시
순마다 날짜, 저장 시각, 다섯 시의 관중 여부랭킹 계산
순 기록·하루 메모·장비·설정 백업기기를 바꾸거나 저장소가 지워졌을 때 본인만 되살림
공개로 고른 메모·태그, 댓글, 신고활쏜얘기 탭
복구 코드의 해시본인 확인 (복구 코드 원문은 저장하지 않음)

3. 카카오·구글 로그인

로그인은 복구 코드를 잃었을 때 기록을 되찾기 위한 선택 기능입니다.

  • 카카오는 동의 항목 없이, 구글은 최소 범위(openid)로만 로그인합니다. 이메일·이름·프로필은 요청하지 않습니다.
  • 로그인 회사가 주는 계정 번호는 원문으로 저장하지 않고, 되돌릴 수 없는 해시 값만 저장합니다.
  • 복구 코드는 그 계정으로 다시 로그인해야만 열리도록 잠가서 보관합니다.
  • 로그인 과정에서 받은 토큰은 계정 번호를 확인하는 데만 쓰고 바로 버립니다.

4. 다른 서비스로 보내는 것

  • 날씨와 근처 활터를 찾을 때, 허락한 경우에만 기기의 위치(위도·경도)를 날씨·지도 서비스(Open-Meteo, MET Norway, wttr.in, OpenStreetMap, 카카오맵)로 보냅니다. 위치는 국궁록 서버에 저장하지 않습니다.
  • 서버는 Supabase에, 앱은 GitHub Pages에 올라가 있습니다.

5. 보관 기간과 지우기

랭킹 참여를 그만두면(겨루기 탭 → 프로필 → "랭킹 참여 그만두기") 서버에 있는 그 궁사의 기록, 백업, 로그인 연결이 모두 바로 지워집니다. 로그인 연결만 끊으려면 설정 탭의 "로그인 연결"에서 "연결 끊기"를 누르면 됩니다. 기기 안의 기록은 설정 탭의 데이터 지우기로 지울 수 있습니다.

6. 광고와 제3자 제공

광고가 없고, 저장한 정보를 다른 곳에 팔거나 넘기지 않습니다.

7. 문의

GitHub 저장소의 Issues로 문의해 주세요.
